# Risk Analysis

## University Library Management System

| Risk ID | Risk Description                     | Likelihood | Impact | Mitigation Strategy                                             |
| ------- | ------------------------------------ | ---------- | ------ | --------------------------------------------------------------- |
| R-01    | Loss of project files                | Medium     | High   | Regularly commit and push files to GitHub.                      |
| R-02    | Lack of time to complete tasks       | Medium     | High   | Follow the project schedule and prioritize important tasks.     |
| R-03    | Incorrect or incomplete requirements | Medium     | High   | Review requirements carefully and collect stakeholder feedback. |
| R-04    | Git or GitHub configuration problems | Low        | Medium | Verify Git configuration and maintain backups.                  |
| R-05    | Errors in UML diagrams               | Medium     | Medium | Review diagrams and ensure they match the requirements.         |
| R-06    | UI prototype usability problems      | Medium     | Medium | Test the prototype with classmates and improve it.              |
| R-07    | Lack of stakeholder feedback         | Medium     | High   | Seek feedback from students and library staff.                  |
| R-08    | Incomplete project documentation     | Medium     | High   | Use a checklist to review all required deliverables.            |

## Risk Monitoring

Project risks will be reviewed regularly throughout development. If a risk occurs, the mitigation strategy will be applied to reduce its impact on the project.
