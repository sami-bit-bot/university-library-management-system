# Work Breakdown Structure (WBS)

## University Library Management System

### 1. Project Planning

1.1 Understand the project scenario  
1.2 Define project objectives  
1.3 Define project scope  
1.4 Identify assumptions and constraints  
1.5 Prepare project schedule

### 2. Project Repository Setup

2.1 Create GitHub repository  
2.2 Create README.md file  
2.3 Create project folders  
2.4 Install and configure Git  
2.5 Maintain project commit history  
2.6 Create GitHub Issues

### 3. Requirements Analysis

3.1 Identify stakeholders  
3.2 Collect stakeholder needs  
3.3 Identify functional requirements  
3.4 Identify non-functional requirements  
3.5 Prepare user stories  
3.6 Define acceptance criteria  
3.7 Prepare Software Requirements Specification (SRS)

### 4. UML Modeling

4.1 Create use-case diagram  
4.2 Create class diagram  
4.3 Create sequence diagram  
4.4 Create activity diagram  
4.5 Review and validate diagrams

### 5. UI Prototype Design

5.1 Create Figma account  
5.2 Design login screen  
5.3 Design student dashboard  
5.4 Design book search screen  
5.5 Design book details and reservation screen  
5.6 Design librarian dashboard  
5.7 Connect screens using prototype interactions

### 6. Testing and Evaluation

6.1 Test book searching workflow  
6.2 Test book reservation workflow  
6.3 Test issuing and returning workflow  
6.4 Collect feedback from two classmates  
6.5 Identify usability problems  
6.6 Improve prototype based on feedback

### 7. Final Documentation

7.1 Prepare project reports  
7.2 Review all project documents  
7.3 Organize diagrams and prototypes  
7.4 Check GitHub repository  
7.5 Prepare final submission

## Expected Deliverables

- GitHub project repository
- Project README
- Project schedule and Gantt chart
- Stakeholder analysis and SRS
- Four UML diagrams
- Five UI prototype screens
- Usability testing report
- Final project documentation
