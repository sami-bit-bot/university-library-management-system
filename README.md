# University Library Management System

## 1. Project Introduction
The University Library Management System (LMS) is a Software Engineering project designed to improve the management of university library operations. The system will help librarians manage books, student memberships, borrowing, returns, reservations, and overdue notifications.

Currently, the library uses manual records or an outdated system. This project aims to propose a modern and organized solution to these problems.

## 2. Project Objectives
The main objectives of this project are:

- To manage library books and their availability.
- To maintain student and faculty member records.
- To manage book borrowing and returning.
- To allow students to reserve books.
- To track overdue books and provide notifications.
- To improve the efficiency and accuracy of library operations.

## 3. Project Scope

### In Scope
- Book management
- Member registration and management
- Book borrowing and returning
- Book reservation
- Overdue book tracking
- Overdue notifications
- Student and librarian dashboards

### Out of Scope
- Online payment system
- Complete software implementation
- Mobile application development
- Integration with external university systems

## 4. Project Assumptions
- Students and librarians will have access to the system.
- The university will provide accurate book and member information.
- Users will have access to computers and an internet connection.
- Librarians will manage book borrowing and returning.
- Each book copy will have a unique identification number.

## 5. Project Constraints
- Limited project development time.
- Limited financial resources.
- The project is focused on analysis, requirements, modeling, and interface prototyping.
- The project will not require complete software implementation.
- The project will use free or accessible software engineering tools.
